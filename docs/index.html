How the rule works

Every day, take the average of the last closing prices. That’s the fast line. Do the same with the last closes and you get the slow line. The fast line covers fewer days, so it follows the price closely; the slow line is smoother and lags behind.

When the fast line crosses above the slow one, recent prices are running ahead of the longer trend, so the rule buys. When it crosses back below, the rule sells everything and waits in cash for the next cross.

Bigger numbers make both lines slower: fewer trades, later exits. Smaller numbers react sooner but get fooled more often when the price is just bouncing sideways. A setting written as 30/75 is the same rule with a 30-day and a 75-day line.

The catch is that every sale is a bet the price will keep falling. In a stock that mostly rises, many of those bets lose, and the rule ends up buying back higher than it sold.
